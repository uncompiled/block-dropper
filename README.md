# Block Dropper

It's a game where you drop blocks into a grid. It's a lot like the game with a T-name, but the primary constraints are that it runs offline and without ads.

## Rules

- *The Game Pieces*: Seven unique shapes are made up of four blocks each. They fall from the top.
- *Controls*: Move left/right, rotate, and accelerate descent (soft drop) or instantly lock in place (hard drop).
- *Clearing Lines*: A full, uninterrupted horizontal line of 10 blocks disappears. Clearing multiple lines at once provides a score multiplier.
- *Levels and Speed*: Every 10 cleared lines increases the level and makes pieces fall faster.
- *Game Over*: When pieces reach the top of the game board and cannot fall, the game ends.
